# UDP 피어 위치 동기화 시험 보고서

> 아래 표는 실제 실행 후 채운다. 예시 수치를 실제 측정값처럼 제출하지 않는다.

## 환경
- 시험 일시: (기록)
- OS / .NET 버전: (기록)
- 주소: 127.0.0.1, A=9000, B=9001

## 기능 시험
| 시험 | 입력/절차 | 기대 결과 | 실제 결과 | 판정 |
|---|---|---|---|---|
| 양방향 위치 | A에서 `3 5`, B에서 `8 2`, 양쪽 `show` | A는 B(8,2), B는 A(3,5) | | |
| 오래된 번호 | A에서 `3 5`, `4 6`, B가 Seq=2 반영 확인 후 A에서 `old` | B는 Seq=1 무시, A(4,6) 유지 | | |
| 같은 번호 | 위 조건에서 A에서 `duplicate` | B는 Seq=2 무시, A(4,6) 유지 | | |
| 잘못된 메시지 | A에서 `invalid` | B가 잘못된 메시지 3건 집계, 수신 지속 | | |
| 종료 | A/B에서 `exit` | 정상 종료 | | |

## 전송량 시험
매 조건은 A/B를 새로 실행하여 통계를 초기화한다. B에서 `stats`를 시험 전 확인하고, A에서 시험 명령을 실행한다. A 송신 종료 후 충분히 기다린 다음 A/B `stats`와 `show`를 기록한다.

| 조건 | A 명령 | A 송신완료 | A 송신오류 | B 수신 | B 위치반영 | B 오래된/중복무시 | B 잘못된메시지 | A 소요(ms) | B 최종 위치/Seq |
|---|---|---|---|---|---|---|---|---|---|
| 1 | `burst 100 10` | | | | | | | | |
| 2 | `burst 1000 0` | | | | | | | | |

- 조건 2 관찰: (실제 수치 및 해석)
- 송신 완료 수와 수신 수가 다를 경우, 관찰 시점의 미도착·OS 버퍼 드롭·네트워크 손실 등 가능성을 구분해야 한다. 차이를 확정 손실로 단정하지 않는다.
- 시험 증빙: 각 피어의 `show`/`stats` 화면 캡처 또는 콘솔 로그 첨부
