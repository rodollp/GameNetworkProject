# NGO 코인 게임 — 테스트 결과 보고서

## 1. 테스트 목적

Unity NGO를 이용한 Host/Client 접속, 플레이어 이동, 코인 획득, 점수 동기화 기능이 정상적으로 동작하는지 확인합니다.

또한 잘못된 코인 ID와 중복 획득 요청에 대해 서버가 안전하게 처리하는지 시험합니다.

## 2. 테스트 환경

| 항목 | 내용 |
|---|---|
| Unity | 6000.6.6f1 |
| NGO | 2.13.3 |
| 실행 환경 | Windows |
| 실행 방식 | 동일 PC에서 Host와 Client 실행 |
| 접속 주소 | 127.0.0.1 |
| 접속 포트 | [실제 포트 입력] |
| 테스트 날짜 | [실제 시험 날짜 입력] |

## 4. 주요 테스트 내용

### T03. 플레이어 입력 분리

**시험 방법**

1. Host를 실행합니다.
2. Client를 접속시킵니다.
3. 각각의 실행 화면에서 이동 입력을 수행합니다.
4. 자신이 소유한 플레이어만 조작되는지 확인합니다.

**기존 문제**

Client를 접속시키면 Host의 입력이 정상적으로 처리되지 않는 문제가 발생했습니다.

**수정 내용**

`InputAction.Clone()`을 이용하여 플레이어별 입력 액션을 분리했습니다.

**확인 내용**

입력 공유 문제를 수정한 후 Host와 Client의 조작 문제를 해결했습니다.

### T05. 코인 획득

**시험 방법**

1. Host와 Client를 실행합니다.
2. 플레이어를 코인 위치로 이동시킵니다.
3. 코인에 접촉하여 획득 요청을 발생시킵니다.
4. 점수 증가와 코인 제거 여부를 확인합니다.

**예상 결과**

서버에서 코인 획득을 승인한 경우 점수가 1 증가하고 코인이 제거됩니다.

**최종 결과**

[실제 실행 결과 입력]

### T08. 잘못된 코인 ID 요청

**시험 방법**

1. `TestInvalidCoinRequest()`를 실행합니다.
2. 존재하지 않는 ID인 `ulong.MaxValue`를 서버에 전달합니다.
3. 서버에서 해당 ID의 오브젝트를 조회하도록 합니다.

**예상 결과**

서버에서 코인을 찾지 못해 요청을 거절하고 점수는 증가하지 않습니다.

**기존 확인 내용**

잘못된 코인 ID 요청에 대한 거절 처리를 시험했습니다.

### T09. 중복 코인 획득

**시험 방법**

1. 하나의 코인에 대해 획득 요청을 발생시킵니다.
2. 동일한 코인에 대한 중복 요청 상황을 확인합니다.
3. 점수가 한 번만 증가하는지 확인합니다.

**예상 결과**

`isCollected` 검사로 중복 획득을 방지합니다.

**기존 확인 내용**

중복 점수 지급 방지 동작을 확인했습니다.

### T11. Client 재접속

**시험 방법**

1. Host와 Client를 실행합니다.
2. 코인을 획득하여 점수를 변경합니다.
3. Client를 종료합니다.
4. Host를 유지한 상태에서 Client를 다시 접속합니다.
5. 남아 있는 코인과 점수 상태를 비교합니다.

**예상 결과**

재접속 후에도 서버의 현재 상태에 따라 코인과 점수 정보가 표시됩니다.

**최종 결과**

[실제 실행 결과 입력]

## 5. 오류 및 수정 기록

| 문제 | 원인 또는 확인 내용 | 대응 |
|---|---|---|
| Client 접속 후 Host 이동 불가 | 입력 액션 공유 문제 | `InputAction.Clone()` 적용 |
| Host 점수 로그 중복 | 플레이어 프리팹 중복 배치 | 중복 오브젝트 수정 |
| 코인 Despawn 경고 | 씬 배치 NetworkObject 제거 방식 관련 | 생성 및 제거 방식 확인 |
| Unity 프로젝트 열기 오류 | 버전 확인 및 설정 파일 경로 오류 | 최종 확인 필요 |


## 6. 최종 결과 및 제한 사항

현재 NGO 코인 게임은 Host/Client 구조, 플레이어 입력 분리, 코인 획득 요청, 서버 검증, 점수 동기화 기능을 중심으로 구현했습니다.

개발 과정에서 입력 공유 문제와 프리팹 중복 문제를 수정했습니다.

다만 최종 제출 환경에서 이동 동기화, 거리 초과 요청, Client 재접속 및 상태 일치 여부를 다시 확인해야 합니다.

테스트를 완료하지 못한 항목은 성공으로 표시하지 않고 미확인 상태로 기록합니다.
