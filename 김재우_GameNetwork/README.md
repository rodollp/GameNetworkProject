# NGO 코인 게임 (GameNetwork)

## 1. 프로젝트 소개

Unity 6와 Netcode for GameObjects(NGO)를 활용하여 제작한 네트워크 코인 획득 게임입니다.

같은 컴퓨터에서 Host와 Client를 실행하여 두 플레이어가 접속하고, 각자 자신의 캐릭터를 조작하며 코인을 획득할 수 있도록 구현했습니다.

코인 획득과 점수 변경은 서버에서 검증하고 처리하도록 구성했습니다.

## 4. 실행 방법

### Unity 프로젝트 열기

1. Unity Hub에서 `CoinGame` 폴더를 프로젝트로 추가합니다.
2. Unity 6000.6.6f1 버전으로 프로젝트를 엽니다.
3. 게임 씬을 실행합니다.

시작 씬: **[실제 씬 경로 입력]**

### Host 및 Client 실행

1. Unity Editor에서 게임을 실행합니다.
2. Host 버튼을 눌러 서버와 Host 플레이어를 시작합니다.
3. 별도로 빌드한 게임을 실행합니다.
4. Client 버튼을 눌러 Host에 접속합니다.
5. 두 실행 화면에서 플레이어의 생성 및 이동을 확인합니다.

### 접속 설정

- 접속 주소: `127.0.0.1` (동일 PC 기준)
- 포트: **[실제 Unity Transport 포트 입력]**
- 설정 위치: `NetworkManager`의 Unity Transport 컴포넌트

## 6. 주요 구현 기능

### 플레이어 이동

- `CharacterController`를 이용하여 플레이어 이동을 구현했습니다.
- `IsOwner`를 이용해 자신의 플레이어만 입력을 처리하도록 했습니다.
- `InputAction`을 복제하여 플레이어별 입력을 관리했습니다.
- 플레이어 위치를 네트워크에서 동기화하도록 구성했습니다.

### 코인 획득

- 플레이어가 코인과 접촉하면 서버에 획득을 요청합니다.
- 서버는 전달받은 코인 ID로 해당 오브젝트를 조회합니다.
- 서버에서 플레이어와 코인 사이의 거리를 검사합니다.
- 이미 획득된 코인은 중복 처리하지 않습니다.
- 정상 요청이면 점수를 증가시키고 코인을 제거합니다.

### 점수 동기화

- `NetworkVariable<int>`를 사용하여 플레이어의 점수를 관리합니다.
- 점수 변경은 서버에서 처리합니다.
- 변경된 점수는 네트워크를 통해 동기화됩니다.

## 7. 정상 실행 확인 방법

다음 항목을 확인합니다.

- Host와 Client가 각각 실행되는지
- 두 플레이어가 정상적으로 생성되는지
- 자신의 캐릭터만 조작할 수 있는지
- 상대 화면에서도 이동 결과가 보이는지
- 코인 획득 시 점수가 증가하는지
- 획득한 코인이 제거되는지
- 잘못된 코인 ID 요청이 거절되는지
- 동일한 코인을 중복 획득할 수 없는지
- Client 종료 후 재접속이 가능한지

실제 시험 결과는 `TEST_REPORT.md`에 기록합니다.

## 8. 설계 내용

수업에서 학습한 NGO의 `NetworkBehaviour`, `NetworkObject`, `NetworkVariable`, RPC 등을 활용했습니다.

특히 코인 획득은 클라이언트가 직접 점수를 변경하지 않고 서버에 요청하도록 구현했습니다.

서버에서 코인의 존재 여부, 거리 조건, 중복 획득 여부를 검증하여 정상 요청에 대해서만 점수를 증가시키도록 설계했습니다.

자세한 설계 과정은 `DESIGN.md`에 기록합니다.

## 9. 알려진 제한 사항 및 미완성 기능

- 동일 컴퓨터에서 Host와 Client를 실행하는 환경을 기준으로 시험했습니다.
- 외부 네트워크를 통한 접속은 별도로 검증하지 않았습니다.
- Unity 버전 및 프로젝트 설정 파일 관련 오류가 발생한 이력이 있어 제출 전 재실행 확인이 필요합니다.
- 종료 및 재접속 등 최종 시험 결과는 `TEST_REPORT.md`에서 확인해야 합니다.
